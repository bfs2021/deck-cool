1.0.0 is the first stable release. Nothing breaks from 0.3.3: update and your deck works as before. From now on the public API follows semver: every export of both packages, the components' props, the `data-slidedeck-*` attributes and the `--deck-*` CSS custom properties change in a breaking way only in a major version.
