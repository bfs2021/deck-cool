# deck.cool

Every site in the `*deck` family: the umbrella site at [deck.cool](https://deck.cool), and one site per package, at slide.deck.cool, page.deck.cool and play.deck.cool. All are built with [Pagedeck](https://github.com/pedrosousa13/pagedeck).

## Design

- **The design canvas:** https://claude.ai/artifact/QjhCKzzVi3X3Bg3WP7fWWR, the source of truth for the look (private to the maintainer).
- **[`CONTEXT.md`](CONTEXT.md):** the decisions: addresses, dark by default, the Family bar, the favicons, the motion.
- **[`design/`](design/):** the favicons as SVG files and the canvas boards' source. [`design/README.md`](design/README.md) says which boards were chosen.
