"@carouseldeck/react-18": minor
---

`@carouseldeck/react-18` supports React 18 and React 19 from one build: its peer range is now `react` and `react-dom` `>=18 <20`. On React 19, install it in place of `@carouseldeck/react` where a dependency needs to run on either version; `@carouseldeck/react` stays the package for an app on React 19 alone.
